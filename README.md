# AFBENESIA - Digital Marketing Website

Website landing page dan dashboard admin untuk program Kelas Kilat Digital Marketing Batch 05. Website ini menampilkan informasi lengkap tentang program pelatihan digital marketing, pendaftaran peserta, dan sistem manajemen peserta melalui dashboard admin.

## 🚀 Live Demo

**[https://anindyawita.github.io/afbenesia-dm05/](https://anindyawita.github.io/afbenesia-dm05/)**

## 🛠️ Tech Stack

- **React 19.2** - UI Library
- **TypeScript** - Type Safety
- **Vite (Rolldown)** - Build Tool & Dev Server
- **React Router DOM 7.13** - Client-side Routing
- **Iconify React** - Icon Components
- **CSS3** - Styling dengan Modern CSS, Flexbox & Grid
- **GitHub Pages** - Deployment Platform

## 📦 Cara Menjalankan

1. **Clone repository**

```bash
git clone https://github.com/anindyawita/afbenesia-dm05.git
cd afbenesia-dm05
```

2. **Install dependencies**

```bash
npm install
```

3. **Run development server**

```bash
npm run dev
```

4. **Buka di browser**

```
http://localhost:5173
```

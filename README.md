# Kelas Kilat Digital Marketing - Batch 05

Landing page dan dashboard admin untuk program pelatihan Digital Marketing oleh AFBENESIA. Fitur utama: responsive mobile drawer navigation, scroll spy, gooey button animation, auto-scrolling testimonials, dan dashboard dengan export CSV & filter data peserta.

##  Tech Stack

- React 19.2 + TypeScript
- Vite (Rolldown)
- React Router DOM
- Iconify React
- CSS3 (Custom animations, SVG filters, Flexbox/Grid)

##  Cara Run

```bash
# Clone & Install
git clone https://github.com/anindyawita/afbenesia-dm05.git
cd afbenesia-dm05
npm install

# Run Dev Server
npm run dev

# Build Production
npm run build
```
